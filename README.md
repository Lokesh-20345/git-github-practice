# Git & GitHub Practice Project

A tiny HTML, CSS, and JavaScript website for practising Git and GitHub.

## Run the website
Open `index.html` in your browser. No installation is required.

## Suggested branch exercise
1. Commit the starter project on `main`.
2. Create a branch: `git switch -c feature/add-about-section`
3. Edit `index.html` and add an About section.
4. Commit the change on that branch.
5. Push the branch to GitHub and open a Pull Request.
6. Merge the Pull Request into `main`.
